# Технологический стек проекта

## Описание проекта

**Автоматизация поднятия резюме на hh.ru** — бот для автоматического поднятия резюме в поиске на сайте hh.ru с запуском по расписанию на удаленном сервере.

## Используемые технологии и инструменты

### Язык программирования
- **Python 3.8+** — основной язык разработки
  - Объектно-ориентированное программирование
  - Контекстные менеджеры для управления ресурсами
  - Обработка исключений и ошибок

### Веб-автоматизация
- **Selenium 4.15+** — автоматизация браузера
  - Управление веб-драйвером Chrome/Chromium
  - Работа с динамическими элементами страницы
  - Ожидание загрузки элементов (WebDriverWait)
  - Действия пользователя (ActionChains)
  
- **WebDriver Manager 4.0+** — автоматическое управление драйверами браузера
  - Автоматическая загрузка и настройка ChromeDriver
  - Управление версиями драйверов

- **Chromium/Google Chrome** — браузер для автоматизации
  - Headless режим для работы на сервере без GUI
  - Настройка опций браузера для стабильной работы

### HTTP-запросы и API
- **Requests 2.31+** — библиотека для HTTP-запросов
  - Работа с REST API hh.ru
  - Управление сессиями
  - Обработка ответов сервера

### Планирование задач
- **Schedule 1.2+** — библиотека для планирования задач
  - Запуск по расписанию (каждые N часов)
  - Гибкая настройка времени выполнения
  - Фоновое выполнение задач

### Управление конфигурацией
- **python-dotenv 1.0+** — загрузка переменных окружения
  - Безопасное хранение учетных данных
  - Разделение конфигурации для разных окружений
  - Удобное управление настройками

### Логирование
- **Loguru 0.7+** — современная библиотека логирования
  - Структурированное логирование
  - Ротация логов по дням
  - Хранение логов с ограничением по времени
  - Цветной вывод в консоль
  - Разные уровни логирования (info, warning, error, success)

### Система развертывания
- **Systemd** — системный менеджер служб Linux
  - Автозапуск при загрузке сервера
  - Управление жизненным циклом процесса
  - Автоматический перезапуск при сбоях
  - Централизованное логирование через journalctl

### Операционная система и инфраструктура
- **Ubuntu 22.04 LTS** — операционная система сервера
- **VDS сервер** — виртуальный выделенный сервер
- **SSH** — удаленное управление сервером
- **rsync** — синхронизация файлов между локальной машиной и сервером

### Инструменты разработки
- **Git** — система контроля версий
- **GitHub** — хостинг репозитория
- **Virtual Environment (venv)** — изоляция зависимостей Python

### Дополнительные инструменты
- **Screen/Tmux** (опционально) — для запуска в фоновом режиме без systemd
- **Cron** (альтернатива) — для планирования задач (не используется, заменен на schedule)

## Архитектура проекта

### Структура кода
- **Модульная архитектура** — разделение на логические модули
- **Классовая структура** — использование ООП для организации кода
- **Контекстные менеджеры** — правильное управление ресурсами (браузер, сессии)
- **Обработка ошибок** — комплексная обработка исключений с логированием

### Основные компоненты
1. **hh_bot.py** — основной модуль бота (1000+ строк)
   - Авторизация на сайте
   - Поднятие резюме
   - Обработка различных сценариев

2. **scheduler.py** — планировщик задач
   - Настройка расписания
   - Запуск бота по расписанию
   - Управление жизненным циклом

3. **config.py** — управление конфигурацией
   - Загрузка переменных окружения
   - Валидация настроек
   - Централизованное хранение конфигурации

## Особенности реализации

### Безопасность
- Хранение учетных данных в переменных окружения (.env)

### Надежность
- Автоматический перезапуск при сбоях (systemd)
- Подробное логирование всех операций
- Обработка различных сценариев ошибок
- Сохранение скриншотов при критических ошибках

### Масштабируемость
- Легкое добавление новых функций
- Модульная структура кода
- Возможность расширения для работы с несколькими резюме

- Детальное логирование всех действий
- Ротация логов с ограничением по времени хранения
- Возможность просмотра логов через systemd journal
