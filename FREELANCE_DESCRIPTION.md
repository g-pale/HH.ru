# Описание проекта для фриланс-биржи

## Краткое описание проекта

**Автоматизация поднятия резюме на hh.ru** — полнофункциональный бот для автоматического поднятия резюме в поиске на сайте hh.ru. Проект включает веб-автоматизацию, планирование задач, развертывание на удаленном сервере и автоматический запуск по расписанию.

## Технологический стек

### Основные технологии:
- **Python 3.8+** — разработка на Python с использованием ООП
- **Selenium 4.15+** — автоматизация браузера для работы с веб-интерфейсом
- **Requests** — работа с HTTP-запросами и REST API
- **Schedule** — планирование и автоматический запуск задач
- **Loguru** — продвинутое логирование с ротацией файлов
- **python-dotenv** — управление конфигурацией через переменные окружения

### Инфраструктура и развертывание:
- **Ubuntu 22.04 LTS** — Linux сервер
- **Systemd** — управление системными сервисами, автозапуск
- **Chromium/Chrome** — браузер для автоматизации в headless режиме
- **Git/GitHub** — контроль версий и хостинг кода
- **SSH/rsync** — удаленное управление и синхронизация файлов

## Реализованный функционал

✅ **Автоматическая авторизация** на сайте hh.ru через веб-интерфейс  
✅ **Поднятие резюме** в поиске с проверкой статуса  
✅ **Обработка различных сценариев**: резюме уже поднято, капча, ошибки  
✅ **Планирование задач**: автоматический запуск каждые 5 часов  
✅ **Работа на сервере**: headless режим без графического интерфейса  
✅ **Системный сервис**: автозапуск через systemd при загрузке сервера  
✅ **Подробное логирование**: все действия записываются в логи с ротацией  
✅ **Обработка ошибок**: сохранение скриншотов при критических ошибках  

## Особенности реализации

### Архитектура
- Модульная структура кода (1000+ строк)
- Использование классов и контекстных менеджеров
- Разделение логики на компоненты (бот, планировщик, конфигурация)

### Надежность
- Автоматический перезапуск при сбоях
- Обработка различных исключительных ситуаций
- Валидация конфигурации перед запуском

### Безопасность
- Хранение учетных данных в переменных окружения
- Исключение чувствительных данных из системы контроля версий
- Защита файлов конфигурации

### Мониторинг
- Детальное логирование всех операций
- Ротация логов с ограничением по времени хранения
- Просмотр логов через systemd journal
