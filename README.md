# Бот для автоматического поднятия резюме на hh.ru

Автоматизация процесса поднятия резюме в поиске на hh.ru. Бот работает на сервере и автоматически поднимает резюме каждые 5 часов.

## 🎯 Описание

Бот автоматически авторизуется на hh.ru и поднимает ваше резюме в поиске. Резюме можно поднимать **раз в 4 часа**, поэтому бот настроен на запуск каждые 5 часов (с запасом).

## ✨ Возможности

- ✅ Автоматическая авторизация на hh.ru
- ✅ Поднятие резюме в поиске
- ✅ Определение, когда резюме уже поднято
- ✅ Обработка капчи (с предупреждениями)
- ✅ Работа на сервере без графического интерфейса (headless режим)
- ✅ Автоматический запуск по расписанию через systemd
- ✅ Подробное логирование всех действий

## 📋 Требования

- Python 3.8+ (рекомендуется 3.10+)
- Chromium или Google Chrome
- Ubuntu 22.04+ (для развертывания на сервере)
- Минимум 512 МБ RAM (рекомендуется с swap 2 ГБ)

## 🚀 Быстрый старт

### Локальная разработка

1. **Клонирование репозитория**
   ```bash
   git clone <ваш_репозиторий>
   cd HH.ru
   ```

2. **Создание виртуального окружения**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

3. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка конфигурации**
   ```bash
   cp .env.example .env
   nano .env  # или любой другой редактор
   ```

   Заполните `.env` файл:
   ```env
   HH_LOGIN=your_email@example.com
   HH_PASSWORD=your_password
   RESUME_ID=your_resume_id
   SCHEDULE_TIME=09:00
   HEADLESS_BROWSER=false  # для локальной разработки
   BROWSER_TYPE=chromium
   ```

5. **Тестовый запуск**
   ```bash
   python hh_bot.py
   ```

## ⚙️ Конфигурация

Все настройки находятся в файле `.env`. Создайте его на основе `.env.example`:

```env
# Учетные данные от hh.ru
HH_LOGIN=your_email@example.com
HH_PASSWORD=your_password

# ID вашего резюме (найдите в URL резюме на hh.ru)
RESUME_ID=your_resume_id

# Настройки расписания (в формате HH:MM, используется если запуск по времени)
SCHEDULE_TIME=09:00

# Настройки для веб-автоматизации
HEADLESS_BROWSER=true      # true для сервера, false для локальной разработки
BROWSER_TYPE=chromium      # chromium или chrome
```

## 🔧 Управление на сервере

### Проверка статуса сервиса

```bash
systemctl status hh-bot.service
```

### Просмотр логов

```bash
# Логи systemd
journalctl -u hh-bot.service -f

# Логи планировщика
tail -f /opt/hh-bot/logs/scheduler_*.log

# Логи бота
tail -f /opt/hh-bot/logs/hh_bot_*.log
```

### Управление сервисом

```bash
# Запуск
systemctl start hh-bot.service

# Остановка
systemctl stop hh-bot.service

# Перезапуск (после обновления кода)
systemctl restart hh-bot.service

# Включение автозапуска при загрузке системы
systemctl enable hh-bot.service

# Отключение автозапуска
systemctl disable hh-bot.service
```

### Обновление кода

```bash
# 1. На локальном компьютере: загрузка обновленного кода на сервер
rsync -avz --exclude '.venv' --exclude '__pycache__' --exclude '*.pyc' \
  /path/to/project/HH.ru/ your-server:/opt/hh-bot/

# 2. На сервере: перезапуск сервиса
ssh your-server
systemctl restart hh-bot.service
systemctl status hh-bot.service
```

## 📝 Логирование

Бот создает подробные логи всех действий:

- **Логи планировщика**: `logs/scheduler_YYYY-MM-DD.log`
- **Логи бота**: `logs/hh_bot_YYYY-MM-DD_HH-MM-SS.log`
- **Скриншоты ошибок**: `logs/*.png` (при ошибках)

Логи ротируются ежедневно и хранятся 30 дней.

## ⚠️ Важные замечания

### О поднятии резюме

- Резюме можно поднимать **раз в 4 часа**
- Бот настроен на запуск каждые 5 часов (с запасом)
- Если резюме уже поднято, бот определит это и сообщит в логах
- Бот корректно обрабатывает ситуацию, когда резюме в кулдауне

### О капче

- При частых попытках входа hh.ru может запросить капчу
- Бот обнаруживает капчу и сообщает об этом в логах
- Если появилась капча:
  1. Подождите 10-15 минут перед следующей попыткой
  2. Или войдите вручную через браузер один раз
  3. После этого бот должен работать нормально

⚠️ **Внимание**: Автоматизация действий на hh.ru может нарушать пользовательское соглашение. Рекомендуется:
- Использовать бота ответственно
- Не злоупотреблять частотой запросов
- Проверить актуальные правила использования hh.ru

## 🐛 Отладка проблем

### Бот не запускается

1. Проверьте, что все зависимости установлены: `pip install -r requirements.txt`
2. Убедитесь, что `.env` файл создан и заполнен правильно
3. Проверьте логи: `tail -f logs/hh_bot_*.log`

### Авторизация не работает

1. Проверьте правильность данных в `.env`
2. Убедитесь, что `HEADLESS_BROWSER=true` на сервере
3. Проверьте скриншоты ошибок в `logs/`
4. Проверьте, не появилась ли капча

### Chromium/Chrome не запускается

1. Убедитесь, что браузер установлен: `chromium-browser --version`
2. Проверьте, что установлены все зависимости (см. DEPLOY.md)
3. Увеличьте swap, если не хватает памяти: `free -h`

### Селекторы не работают

Интерфейс hh.ru мог измениться. Проверьте логи и обновите селекторы в коде.
