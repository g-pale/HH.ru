# Материалы, необходимые для реализации бота

## 📋 Список необходимых материалов

### 1. Учетные данные от hh.ru

#### Вариант А: Логин и пароль
- **Email или телефон**, используемый для входа на hh.ru
- **Пароль** от вашего аккаунта

#### Вариант Б: OAuth токен (для API)
- **Client ID** и **Client Secret** от приложения в [личном кабинете разработчика hh.ru](https://dev.hh.ru/)
- **Access Token** (получается после авторизации через OAuth)

### 2. Информация о резюме

- **ID вашего резюме** - можно найти в URL резюме:
  - Откройте ваше резюме на hh.ru
  - В адресной строке будет URL вида: `https://hh.ru/resume/{RESUME_ID}`
  - Скопируйте `RESUME_ID` (например: `abc123def456`)

### 3. Технические требования

- **Python 3.8+** (у вас установлен Python 3.13 ✅)
- **Интернет-соединение** для работы бота
- **Компьютер или сервер**, который будет работать 24/7 (или можно использовать облачные сервисы)

### 4. Дополнительное программное обеспечение

- **Google Chrome** (для веб-автоматизации через Selenium)
- Или **Firefox** (если выберете этот браузер)

## 🔧 Настройка проекта

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2: Создание файла конфигурации

1. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. Откройте файл `.env` и заполните его своими данными:
   ```env
   HH_LOGIN=your_email@example.com
   HH_PASSWORD=your_password
   RESUME_ID=your_resume_id
   SCHEDULE_TIME=09:00
   ```

### Шаг 3: Тестовый запуск

Перед настройкой автоматического запуска проверьте работу бота:

```bash
python hh_bot.py
```

### Шаг 4: Запуск планировщика

После успешного тестирования запустите планировщик:

```bash
python scheduler.py
```

## ⚠️ Важные замечания

### Официальный API hh.ru

**ВАЖНО**: Нужно проверить, есть ли в официальном API hh.ru метод для поднятия резюме. 

1. Зайдите на [dev.hh.ru](https://dev.hh.ru/)
2. Зарегистрируйте приложение
3. Изучите документацию API на предмет методов работы с резюме
4. Если метод есть - используйте его (более надежный способ)
5. Если метода нет - используйте веб-автоматизацию

### Пользовательское соглашение

⚠️ **Внимание**: Автоматизация действий на hh.ru может нарушать пользовательское соглашение. 

Рекомендации:
- Используйте официальный API, если он доступен
- Добавьте задержки между действиями (уже реализовано)
- Не злоупотребляйте частотой запросов
- Проверьте актуальные правила использования hh.ru перед запуском

### Безопасность

- **НЕ коммитьте** файл `.env` в git (он уже в `.gitignore`)
- Храните учетные данные в безопасности
- Используйте отдельный тестовый аккаунт для проверки работы бота

## 📝 Дополнительная информация

### Альтернативные варианты запуска

#### Вариант 1: Локальный запуск
- Запустите `scheduler.py` на вашем компьютере
- Компьютер должен быть включен 24/7

#### Вариант 2: Облачный сервер
- Разверните бота на облачном сервере (AWS, DigitalOcean, Heroku и т.д.)
- Используйте systemd или supervisor для автозапуска

#### Вариант 3: GitHub Actions (бесплатно)
- Можно настроить GitHub Actions для запуска бота по расписанию
- Требует хранения учетных данных в Secrets GitHub

### Отладка

Если что-то не работает:
1. Проверьте логи в папке `logs/`
2. Убедитесь, что все данные в `.env` заполнены правильно
3. Попробуйте запустить бота с `HEADLESS_BROWSER=false` для визуальной отладки
4. Проверьте, что селекторы кнопок актуальны (интерфейс hh.ru может измениться)

## 🆘 Поддержка

Если возникнут проблемы:
1. Проверьте логи в папке `logs/`
2. Убедитесь, что все зависимости установлены
3. Проверьте актуальность селекторов на сайте hh.ru (они могут измениться)
